# Amethyst optics {#amethyst-optics}

Find a clear path for a beam, then add mirrors and lenses one at a time. Adjusting one component at a time makes changes in the optical path easier to follow.

<img class="item-icon" src="/assets/amethyst-crystal-sheet.png" alt="The mod's amethyst crystal sheet item icon" width="64" height="64" />

## Meet the components {#components}

- **Emitter**: the starting point of the optical path.
- **Amethyst Mirror**: redirects a beam.
- **Lens**: changes how a beam converges or diverges.
- **Receiving device**: uses the light that reaches it.

## Try a small experiment {#first-experiment}

Start with a short, straight path. Add one mirror and observe the redirected beam. Once you are comfortable with direction changes, try a lens or a longer route.

::: tip Leave enough room
An optical layout depends on more than its centre line. Consider the beam's width and the clear aperture of each component too.
:::
