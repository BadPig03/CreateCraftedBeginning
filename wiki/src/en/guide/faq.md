# Questions & answers {#faq}

## How do I change the language? {#languages}

Use the language menu at the top of the page. Every sample page has a matching Chinese version, so switching languages lets you keep reading the same article.

## Do I need an account to search? {#search}

No. Search uses a document index generated for this site and runs in your browser. There is no sign-in or external search service to set up.

Try searching for “airtight pipe” or “amethyst”. Switch to Chinese to try “气密管道” or “紫晶”. Results use the language you are currently reading.

## Why are there only a few pages? {#preview}

This is the first wiki preview, built to try reading, navigation, search and language switching. Device specifications, installation instructions and detailed tutorials will be added over time.

## How do I report a documentation issue? {#feedback}

Use “Edit this page on GitHub” at the bottom of an article to propose a change, or describe the issue in the [project's issue tracker](https://github.com/BadPig03/CreateCraftedBeginning/issues).
