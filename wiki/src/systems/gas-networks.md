# 气体网络 {#gas-networks}

把气体系统拆成三部分来看：哪里供气、沿什么路线输送、最终由什么设备用气。

<img class="item-icon" src="/assets/gas-canister.png" alt="模组中的气罐物品图标" width="64" height="64" />

## 从一条短管路开始 {#start-small}

先认识气罐与气密管道，再考虑更复杂的网络。气密管道提供被动通路，本身不会产生压力；接上管道不等于已经具备供气条件。

```text
供气端 → 气密管道 → 用气设备
```

这是一张角色示意图。具体接口、供气方式与工作条件，要按所用设备确认。

## 管道与泵各做什么 {#parts}

| 部件 | 先理解的作用 |
| --- | --- |
| 气罐 | 存放与携带气体 |
| 气密管道 | 连接气体设备，形成输送路线 |
| 泵与阀门 | 调整输送和通断，具体能力依设备而定 |

::: tip 保持实验简单
测试时先使用一种气体和一条短路线。确认两端接口与工作条件后，再扩展分支。
:::
