# 常见问题 {#faq}

## 怎么切换中英文？ {#languages}

使用页面顶部的语言菜单。当前示例页面都有对应的英文版本，切换语言后可以继续阅读同一篇文章。

## 搜索需要账号吗？ {#search}

不需要。搜索在浏览器中使用本站生成的文档索引，不需要登录或申请外部搜索服务。

可以试试搜索“气密管道”“紫晶”，再切到英文搜索“airtight pipe”或“amethyst”。搜索结果按当前语言显示。

## 为什么现在只有几篇文章？ {#preview}

目前是 Wiki 测试版，先验证阅读、导航、搜索与中英文切换。设备参数、安装说明和详细教程会逐步补充。

## 怎么反馈内容问题？ {#feedback}

使用页面底部的“在 GitHub 上编辑此页”提交文档修改，或前往[项目 Issues](https://github.com/BadPig03/CreateCraftedBeginning/issues)说明问题。
